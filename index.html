极品事件（一）“香肠”事件

极品帮参与者：WYC

将文件下载到本地，直接用浏览器打开即可预览。

# 克隆仓库
git clone https://github.com/yourname/docshub.git
cd docshub

# 直接用浏览器打开 index.html

通过 CDN 引入

<link rel="stylesheet" href="https://cdn.example.com/docshub/style.css">
<script src="https://cdn.example.com/docshub/app.js"></script>

基础配置

在 config.js 中修改站点信息：

export default {
  title: '我的文档',
  theme: 'dark',        // dark | light
  sidebar: true,        // 是否显示左侧目录
  search: true          // 是否启用搜索
}

配置项说明

参数类型默认值说明
titlestring'DocHub'站点标题
themestring'dark'默认主题
sidebarbooleantrue显示侧边栏
searchbooleantrue启用搜索

使用示例

最简单的页面结构：

<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <title>我的文档</title>
  <link rel="stylesheet" href="style.css">
</head>
<body>
  <h1>Hello, DocHub!</h1>
  <script src="app.js"></script>
</body>
</html>
⚠️ 注意：确保 style.css 和 app.js 路径正确，否则样式和交互可能失效。

API 参考

init(config)

初始化文档站点，接收配置对象。

import { init } from 'docshub';

init({
  title: '我的项目',
  theme: 'light'
});

setTheme(mode)

动态切换主题，mode 为 'dark' 或 'light'。

import { setTheme } from 'docshub';

setTheme('dark');

常见问题

如何自定义主题色？

修改 CSS 变量中的 --accent 值即可：

:root {
  --accent: #ff6600;  /* 改为你喜欢的颜色 */
}

移动端侧边栏不显示？

点击左上角 ☰ 按钮即可展开/收起侧边栏。这是为小屏幕设计的交互方式。
